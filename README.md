# Cosmological parameter estimation

MCMC fits of cosmological models to Cosmic Chronometer and Pantheon+SH0ES data.

The main Python notebook is `emcee_implementation.ipynb`; reusable code is in `src/`.

## Run

Install `numpy`, `scipy`, `matplotlib`, `emcee`, and `corner`. Then open `emcee_implementation.ipynb` in Jupyter and run its cells.
